    Trial balance import

    Import one or more trial balances as CSV or Excel, for example one per property or sector. Each account is matched to a line item in the federal checker by its name and number. Review the matches, change any that are wrong, then apply them to the checker.

    Expected columns: account number, account name, and either debit and credit or a single balance (debits positive). Asset tests use value, so adjust book balances to fair value where they differ. Book income and expenses give an estimate of REIT taxable income only.

    You can import several trial balances, one per property, entity or portfolio: choose several files at once, or import them one after another. Give each its property sector and the REIT's share. The checker uses the combined figures.

    State estimated taxes

    Estimates for each state on the client dashboard, using the REIT's taxable income and distributions from the federal checker or the imported trial balance. Enter receipts sourced to each state to apportion income. Most states use a single receipts factor for REITs; check each state's rules.

    State rules

    Most states with a corporate income tax start from federal taxable income and allow the REIT dividends-paid deduction. The exceptions usually target captive REITs, those controlled by a single corporation. Tap a filter to narrow the list.

    International REIT regimes

    Key qualification features of major REIT regimes. Distribution and asset rules vary widely, and some regimes have narrowed recently.

    Rule updates

    The rule review runs every morning. It checks for new federal, state and international REIT rule changes, verifies existing rules against current sources, and adds coverage. Each day's review is logged below, even when nothing changed. Rule changes it finds are listed after the log, dated when the change was made, with links to their sources.
